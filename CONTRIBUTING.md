# Contributing to CyberGod

We are grateful for your interest in contributing to this Open Source software project.
We are a new project, building our craft while already in flight — please pardon any bumps you experience in your journey toward contributing to this project.

Any kind of contribution is welcome and valuable:  documentation, how-to and promotional content, testing and bug reports, feature requests and code for new features, issues and pull requests (PRs), and questions in the forums online or in person at an event.
If you are already a CyberGod user, we thank you for the valuable time and attention you have spent so far.

## Making a feature request, filing a software bug report, and sharing new ideas

Thank you for your interest in helping the project in these valuable ways.
Here are the steps to follow for each of the ways.

### Feature request

The CyberGod community uses the GitHub issue system for tracking feature requests.

1. Navigate to https://github.com/cybergodai/cybergodai/issues
2. Click on the **New issue** button to open a new issue.
3. For the title in **Add a title**, give a concise description of the feature request.
   For example, "Please create a CyberGod package for Firefox web browser".
4. Under **Add a description** put in a thorough description of the request, including details to explain why the feature is needed or valuable.
5. When you are complete, click the **Submit new issue** to send us your request.

Our intention is to reply to feature requests within 72-hours of the request being filed.
If you have any follow-up questions at anytime, write them as a comment into the issue you have already filed.
This keeps all the discussions around the request in a single location.

### Bug/issue report

The CyberGod community uses the GitHub issue system for tracking bug reports, including some security reports.
For any security report, you may not want to file some or all of the details of the situation.

If you do have a potential or suspected security issue with the CyberGod software, email security@cybergod.ai.

To file a bug report for a suspected software defect:

1. Navigate to https://github.com/cybergodai/cybergodai/issues
2. Click on the **New issue** button to open a new issue.
3. For the title in **Add a title**, give a concise description of the defect or its visible effects.
   For example, "Windows 11 installer for CyberGod is extremely slow".
4. Under **Add a description** put in a clear and concise description of the issue you are experiencing.
   Provide details of the buggy behavior and steps to reproduce the issue.
   Include any relevant error messages or logs.
5. When you are complete, click the **Submit new issue** to send us your bug report.

Our intention is to reply to bug reports within 72-hours of the request being filed.
For suspected security bugs and reports, we intend a 12- to 36- hour response window, depending on various factors.

If you have any follow-up questions at anytime, write them as a comment into the issue you have already filed.
This keeps all the discussions around the bug report or security issue in a single location.

### New idea

The CyberGod community uses the GitHub issue system for people to submit general ideas or concerns that are not about the software itself.
This method is in addition to our other communication forums.
Read more about communicating with the CyberGod project in [our README file](https://github.com/cybergodai/cybergodai#project-communication).

1. Navigate to https://github.com/cybergodai/cybergodai/issues
2. Click on the **New issue** button to open a new issue.
3. For the title in **Add a title**, give a concise description of the new idea or general concern.
   For example, "Let's bring CyberGod EPP to the classroom!"
4. Under **Add a description** put in a thorough description of the idea or concern, including details to explain why the idea is useful or why the concern is needing attention.
5. When you are complete, click the **Submit new issue** to send us your idea or concern.

Our intention is to reply to new ideas or concerns within 72-hours of the request being filed.
If you have any follow-up questions during that window or at anytime, write them as a comment into the issue you have already filed.

If your concern is related to interpersonal conduct with one or or members of this project, refer to the [Code of Conduct](https://github.com/cybergodai/cybergodai/blob/main/CODE_OF_CONDUCT.md) for more information.

## Getting Started

To get started with contributing code and content to CyberGod, please follow these steps:

1. Fork the `cybergodai` repository on GitHub.
2. Clone your forked repository to your local machine.
3. Create a new branch for your changes.
    - You can use a common format for a branch name, such as `username/[feature|bug]/short-name-for-patch`.
4. Make your desired changes to the codebase.
5. Test your changes thoroughly.
6. Commit your changes with descriptive commit messages.
7. Push your changes to your forked repository.
8. Submit a pull request to the main [CyberGod repository](https://github.com/cybergodai/cybergodai).

For information on how to conduct these steps, you can use the GitHub [Open Source guide](https://opensource.guide/how-to-contribute/).
